# プロンプト・ツールプロファイル (`harness/profile`)

**言語:** [English](../../../../harness/profile/README.md) | 日本語

`harness/profile` パッケージは、Host 構成時にモデルファミリーに応じたプロンプトおよびツール説明文の調整（Profile）を解決し、`provider.Selection` とともに Host メタデータへ記録します。

---

## 組み込みプロファイル

モデル名の部分一致（substring）ではなく、明示的に宣言されたプロバイダ／モデルファミリーに基づいて解決されます。

- **`conservative` (`v1`):** 観測されたファイル内容とリビジョン確認に関する標準ガイダンスを付与する既定プロファイル。
- **`openai-reasoning` (`v1`):** OpenAI の推論モデルファミリー向けに、既存のツール説明文へ `read` / `edit` / `write` の簡潔な利用ガイダンスを追加するプロファイル。

### 設計上の境界

`Compose` はプロンプトとツール説明文のテキスト構成のみを行います。有効なツール集合、ツール名、引数の JSON スキーマは一切変更せず、権限ポリシーや認証情報、セッション制御 API には関与しません。
