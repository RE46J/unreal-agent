# サブエージェント・Operation ビューア (`harness/viewer`)

**言語:** [English](../../../../harness/viewer/README.md) | 日本語

`harness/viewer` パッケージは、親子の Session 状態、稼働中の Operation、およびトークン統計を TUI 等へ投影するための読み取り専用クライアント（および制御アダプタ）です。このパッケージ自身がストアを直接開いたり、書き込みロックを取得したり、プロセスや LLM を起動したりすることはありません。

---

## 1. フロントエンドへの組み込み

1. `SubagentOptions()` で `Model` を作成し、`NewClient(reader, model, controls)` でクライアントを初期化します。
2. `ParentReader` は接続中の親セッションと、その正規 `SubagentStart` Operation から特定された子セッション群に読み取り範囲を限定します。
3. `Watch(ctx, sessionID, onChange)` で1セッションにつき1つの購読を開始し、更新時に UI の再描画コールバックを呼び出します（オフラインの子などの単発再構築には `Refresh` を使用します）。
4. `Model.Select`、`Model.Rows`、`Model.Detail` で一覧・詳細を取得し、過去の会話ページは `Client.History`（`NextAfter` カーソル）で読み取ります。

---

## 2. 状態判定とトークン集計の原則

- **親から見た実行状態:** 最新の親 Operation レコードが実行中・キャンセル状態を表します。
- **子の完了報告 (`Finish`):** 子の正規 `Finish` レコードのみを根拠とし、プロセスの終了やアシスタントの文章から完了を推測しません。
- **生存状態と再同期:** 切断やイベント欠落（gap）が発生した場合は状態を `unknown`（不明）とし、スナップショットから再同期します。
- **重複しないトークン集計:** トークン使用量は永続化されたモデル応答を `セッション / ターン / 応答ID` で重複排除して合算するため、再接続やリプレイで二重計上されません。プロバイダから報告がない項目は `0` ではなく `unknown` として扱います。
- **メモリ上限とサニタイズ:** 会話キャッシュは既定で 128 件（最大 4,096 件）に制限され、すべての表示ヘルパーは端末制御文字を除去します。

---

## 3. CLI からの子セッション操作コマンド

対話型 TUI では、既存のプライベート Unix ソケット上の拡張ハンドラを通じて以下のコマンドを提供します。
- `/child <ID>` — 対象の子を選択（フォーカス）し、1秒ごとにスナップショットを更新します。
- `/child-history [after] [limit]` / `/child-next` — 子の永続化履歴をページ単位で表示します。
- `/child-send <TEXT>` / `/child-cancel` / `/child-resume` — 安定した `InputID` を付与して親 Host へ制御リクエストを委譲します。
- `/child-retry` — 送信結果が不明な制御リクエストを元の `InputID` のまま安全に再送します。
