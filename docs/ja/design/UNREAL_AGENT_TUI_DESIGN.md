# Unreal Agent TUI デザイン仕様書

**言語:** [English](../../design/UNREAL_AGENT_TUI_DESIGN.md) | 日本語

- **対象:** `bin/unreal-agent attach` の対話型ターミナル UI（Linux / macOS / WSL）
- **性質:** 実装済みの表示仕様（2026-10-28）。表示データの根拠と検証方法を含む。
- **前提:** TUI はバックグラウンド Host の状態を描画する投影（disposable projection）であり、表示する値はすべて既存の projection（`tui.Snapshot` / `host.View` / `viewer.Row`）から得られるものに限定する（付録A参照）。

---

## 0. 本書の読み方と表記規則

- **言語の使い分け:** 見出し・状態語は日本語、キー操作・コマンド名・ツール名は英語とする（詳細は 7.2 参照）。
- **モックアップ中の記号:**
  - `█` = 端末のハードウェアカーソル位置
  - 行頭が `…` だけの行 = 省略された行
  - 色と文字属性は 7.2〜7.5 の表で定義する
- **サイズ表記:** 「列（幅）× 行（高さ）」。実画面は右端1列を常に空ける（7.6）。日本語（CJK）は1文字＝2セル幅として計算する（7.7）。

## 1. デザイン目標 (Design Goals)

| # | 目標 | 意味 |
|---|---|---|
| **G1** | 会話が主役 | 会話と稼働中の作業を優先し、裏の作業は件数の1行、終了した子はビーズにまとめる。 |
| **G2** | 「今」を一目で | ライブ状態（AI の作業フェーズ・ツール・子エージェント・接続状態）は常に決まった位置に出し、位置と記号で即座に判別できるようにする。 |
| **G3** | 平常は静か、異常は明確 | 平常時は件数・記号に圧縮し、失敗・動きなし・要確認は状態の語と強い色帯で示す。 |
| **G4** | 正規履歴と一時表示の分離 | ストリーミング中のドラフト（`⋮`）、送信中表示、通知は、確定済みの正規履歴（canonical history）と見間違えない形で出す。 |
| **G5** | 並列エージェントはカード表示 | 子エージェントは系統順の2行カードで示す。`[A]`, `[B]`, `[C]`… の共通の目印を、起動チップ・カード・裏の作業行で共用する。 |
| **G6** | キーボードのみで発見可能 | `/` でコマンド候補を表示する。キーヒントは文脈で変わり、`Ctrl-C` の「今の意味」を常に示す。 |
| **G7** | 色深度・文字幅に対する安全性 | 色帯と記号で状態、バーと棒グラフで量を示す。前景色と背景色を組にし、truecolor・256色・16色・`NO_COLOR`・Plain・ASCII に対応する。 |
| **G8** | 投影（Projection）として誠実 | 不明な値は `—`・`?`・非表示にする。推測で補わず、「動きなし 8分」のように観測した事実だけを表示する。 |

## 2. 画面構成とモックアップ

### 2.1 Split ビューの構成（端末幅 120 列以上の初期表示）

色付き区画を `[ ]` で示す。カードは通常2行で、孫エージェントは深さごとに2セル字下げする。

```text
┌────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
│ [jh] [● 稼働中 7h45m] [Full Access] [Claude Opus 5.5 · max]                                                                    │
├ チャット（左） / 作業ペイン（右） ─────────────────────────────────────────────────────────────────────────────────────────────┤
│▎ 実装とレビューを進めて                                                │▌◆ メイン                                 7h45m        │
│                                                                        │▌    考え中 6s                            ▂▃▅▃▂▁▂▃▅▃   │
│● 作業を渡しました。                                                    │                                                       │
│  [✓ Read AGENTS.md]                                                    │▌[A] 表示の実装           gpt-6.1-sol·xhigh 1h12m       │
│  [▸ [A] 表示の実装]                                                    │▌    Bash go test ./…                     ▂▃▅▇▅▃▂▅▇▅   │
│                                                                        │  ▌[B] 独立レビュー       gpt-6.1-sol·high 58m         │
│  ┄ 裏の作業  2ターン · ツール3回 · 報告 [A][C]                         │  ▌    応答待ち                           ▁▂▃▂▁▂▃───   │
│                                                                        │▌[C] 調査                  gpt-6.1-sol·high 40m        │
│● 【要確認】失敗の扱いを確認してください。                              │▌    動きなし 8分                         ▅▃────────   │
│⠁ 考え中 6s                                                             │▌[F] Issueの整理           gpt-6.1-sol·high ✗ 失敗     │

│                                                                        │終了 ✓✓✗✓✓  ほか 795                                   │

│ ▲ 要確認  失敗の扱いを確認してください。  ↑ 会話で確認                                                                         │
├ キーバー（高さ16行以上） ──────────────────────────────────────────────────────────────────────────────────────────────────────┤
│  ⏎ send   / commands   ^C stop session   ^D detach                                                                             │
├ 罫線 ──────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┤
│› Ask, or type / for commands                                                                                                   │
├ ゲージ（1行） ─────────────────────────────────────────────────────────────────────────────────────────────────────────────────┤
│文脈 ▕█████░░░░░░░▏394k (39%) · 速度 ▂▃▅▇▆▅ ~69.0 tok/s · キャッシュ ▕██████████▏98.37%                                   │
└────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┘
```

### 2.2 3つのビュー (`/view`)

- **Split:** 120列以上で会話と作業カードを左右に並べる。120列未満では自動的に Chat に切り替わり、幅が戻れば Split に戻る。
- **Chat:** 会話を中心に表示する。120列以上で子がいれば右側にも同じカードを出す。右ペインがない幅では子のドックを1行で出す。
- **Orchestration:** 会話の領域全体を作業カードと終了ビーズの一覧に使う（`PgUp` / `PgDn` でスクロール）。

## 3. 詳細デザイン仕様

### 7.1 画面領域の定義 (Screen Anatomy)

空のドックと要確認の帯は 0 行になる。

| 領域 | 行数 | 表示条件 | 内容 |
|---|---|---|---|
| **R1 Header** | 1 | 常時 | セッション名、状態、権限、モデルの色帯 |
| **R2 Transcript** | 可変（残り全部） | Chat / Split | 発話、ツールチップ、裏の作業の要約、制御入力、ドラフト |
| **R3 Pulse** | 0〜1 | 作業フェーズがあるとき（7.10） | 会話領域の最終行。スピナー＋フェーズ名＋経過時間 |
| **R4 Dock** | 0〜可変 | 中身があるとき | 子の1行要約または focus シート、ヘルプ/解析シート、接続・設定の状態行、通知 |
| **R5 Rule** | 1 | 常時 | 入力欄の上の罫線。入力モードやスクロール位置を表示 |
| **R6 Composer** | 1〜8 | 常時 | `›` と入力テキスト。コマンド入力時は `cmd` チップ |
| **R7 Keybar** | 0〜1 | 高さ16行以上 | 文脈依存のキーヒント（Rule の直上） |
| **R8 Work pane** | 右列またはメイン領域 | Split / Orchestration、または120列以上の Chat で子がいるとき | メインと子のカード、終了のビーズ |
| **R9 Attention** | 0〜1 | 失敗・承認待ち・要確認があるとき | 全幅の帯（Keybar の直上、7.10） |
| **R10 Gauges** | 1 | 常時 | 入力欄の下。文脈、速度、キャッシュ（7.10） |

#### ガター（左端2列）と縦軸

会話はすべて2列ガター（記号1列＋空白1列）で、本文は3列目から始まる（本文の最大幅は100セル）。

```text
▎ あなたの発言（全行に▎、本文の幅まで背景色を塗る）
● agentの連続する発言の先頭
⋮ ドラフト（全行）
⠁ 考え中 6s
✗ エラー本文
· 停止要求
  ✓ Read AGENTS.md （ツールチップ）
```

### 7.2 視覚的階層と日本語化の範囲

| レベル | 見せ方 | 対象 |
|---|---|---|
| **L1 強** | 色帯・記号・強調 | ヘッダー、要確認の帯、失敗、動きなし |
| **L2 通常** | normal、チップとカードの面 | 会話本文、子の題名、ツール名と対象、pulse の語 |
| **L3 弱** | dim / faint | 経過時間、活動棒、ゲージの数値、裏の作業、制御入力、キーヒント |
| **非表示** | 通常時は隠す | 子の内部 ID、op ID、revision、turn、observed、内部操作ノード |

| 日本語にする要素 | 英語のままにする要素 |
|---|---|
| ヘッダーの状態、カード、ビーズ、ゲージ、要確認の帯、チップの状態語、裏の作業、通常の制御入力、pulse、状態ドック、focus の見出し | キーバー、罫線のラベル、入力欄のプレースホルダー、通知、ピッカー、`/help`、コマンド名と説明、ツール名・モデル名・権限名 |

### 7.6〜7.7 レスポンシブ幅と会話描画

- **120列未満:** Split は Chat として表示（右ペインなし、子のドックは1行）。
- **120〜159列:** 右ペイン幅は Split で `clamp(幅×0.3, 34, 44)` 列、Chat（子あり）で `clamp(幅×0.3, 34, 48)` 列。
- **160列以上:** 右ペイン幅は Split で `clamp(幅×0.3, 48, 60)` 列、Chat で `48` 列。
- **裏の作業の折りたたみ:** 子・peer の連絡とそれに続く親の応答・起動は `┄ 裏の作業  21ターン · ツール47回 · 報告 [A][C][D]` の1行にまとめる。ただし `【報告】` / `【要確認】` で始まる発言とエラーは全文を表示してまとまりを区切る。
- **遅延ページ読込:** 初回表示は末尾 128 アイテムから構成し、`PgUp` 等で先頭に近づいたときに前の 128 アイテムを順次読み込む（`InspectBefore`）。
- **コードブロック:** フェンス行は faint で残し、空白折り返しを行わず、折り返し継続行にはガター境界に `↪` を置いてマウス選択コピー時に余計な装飾文字が混ざらないようにする。

### 7.8〜7.9 ツールチップとサブエージェント（子カード・ビーズ）

- **ツールチップ:** 1呼び出し＝1チップ（最大40セル）。同一応答内で同じツールの完了が3回以上あれば `✓ Bash ×3` に畳み、実行中・失敗・取消・承認待ち・`SubagentStart` は個別に表示する。
- **子の共通目印:** すべての子を `(CreatedAt, ID)` 順に並べ、`[A]`〜`[Z]`, `[AA]`〜`[ZZ]` を振る。
- **作業カード（2行固定）:**
  - 1行目: 目印、題名（1行目）、右寄せの `モデル·effort 経過時間`（失敗時は `✗ 失敗`）。
  - 2行目: 現在の操作または Activity（5分以上更新がなければ `動きなし N分`）、右端に直近10分の活動の棒（1分×10セル）。
- **終了のビーズ:** 完了・取消済みの子は作業ペイン下部の `終了 ✓✓✗✓⊘  ほか N` にまとめる（稼働中の子孫を持つ失敗や、ユーザーの最新発言より後の失敗は赤いカードのまま残す）。

### 7.10〜7.13 ヘッダー・Pulse・要確認の帯・ゲージ・入力・コマンド

- **ヘッダーの色帯:** 左から `[セッション名]` `[状態＋経過]` `[権限]` `[モデル·effort]`。
- **Pulse の優先順:** (1) `再試行中（N回目）` → (2) 本文あり streaming `生成中` → (3) 本文なし streaming `考え中` → (4) `応答待ち` → (5) ツール実行中 `Bash 実行中` / `ツールN件 実行中` → (6) `WaitingForModel` `考え中` → (7) 子または裏のターンが稼働中 `裏で作業中 子N`。
- **要確認の帯（Keybar 直上・全幅1行）:** (1) セッション失敗 `✗ ...` → (2) 承認待ち `▲ 承認待ち N件  /permissions` → (3) 未回答の `【要確認】` 発言 `▲ 要確認  ...  ↑ 会話で確認`。
- **下段ゲージ:** `文脈`（12セルバー＋トークン数と割合）、`速度`（直近8件の棒グラフ＋`tok/s`）、`キャッシュ`（10セルバー＋小数2桁の%）。

## 4. 実装受入基準（AC-01〜AC-50）とビジュアル検証

レイアウト境界（AC-01〜05）、ヘッダーと不明値表記（AC-06〜08）、会話・禁則処理・コードブロック（AC-09〜13）、ドラフトと Pulse（AC-14〜17）、ツールチップ（AC-18〜21）、子エージェントカードとビーズ（AC-22〜29）、ハードウェアカーソルと入力（AC-30〜34）、コマンドとヘルプ（AC-35〜37）、エラーと切断・停止状態（AC-38〜42）、`NO_COLOR` / Plain / ASCII（AC-43〜46）、サニタイズとちらつき防止（AC-47〜50）の計50項目で検証する。

## 付録A. 表示要素とデータの対応

| UI 要素・値 | 情報源 | 備考 |
|---|---|---|
| セッション名・接続・ランタイム | `Snapshot.ID` / `Connected` / `Status` / `OfflineSince` / `Running` / `Failure` | 接続異常時はヘッダーの状態区画を置き換える |
| モデル・effort・文脈上限 | `Snapshot.Selection`（`RuntimeSelection`） | `ContextWindow` が 0 なら上限不明（バー非表示） |
| 経過時間 | メインの `viewer.Row.Elapsed` | 累計 Usage は `/analyze` で確認 |
| 会話エントリ | `host.HistoryItem` から `Entry` へ変換 | 描画処理は canonical history を変更しない |
| チップの状態・理由・経過 | Receipt と最新 Operation、`viewer.OperationRow.Elapsed` | `CallID` / `OperationID` で照合 |
| ツールの対象表示 | `viewer.SafeToolTarget` | 許可された安全な表示引数のみ |
| 子の起動・状態・題名 | `OperationIntent.OperationID` と `Row.ParentOperationID` / `Label` / `Finish` / `NeedsResync` | 未観測の子には Activity や Usage を出さない |
| 直近の活動棒グラフ | `Row.RecentActivity` / `LastActivityAt` | 最新256件の canonical item の `RecordedAt` から直近10分を集計 |
| ドラフト・Pulse | `Snapshot.Progress` / `WaitingForModel` / `LatestAt` | 一時表示（確定応答または切断時に消去） |
| 文脈・速度・キャッシュ | `Progress.Statistics`、`LastGeneration`、`SpeedHistory`、`CacheLatest` | Claude の文脈は最後の `message_start` の `input + cache_read + cache_creation` |
| 承認待ち・要確認 | `Snapshot.Permissions.Pending`、`Snapshot.Entries` | 全幅の「要確認の帯」に表示 |
| Project Instructions | `Row.ProjectInstructions` | `source`・`bytes`・`digest` のみ（本文は表示しない） |
